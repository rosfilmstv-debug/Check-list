# Shirley

Checklist sencilla por voz y categorías.

## Qué hace
- Añadir elementos escribiendo o dictando.
- Intenta separar una frase en varios elementos.
- Clasificación automática básica por categorías.
- Tres estados: Comprar → Comprado → Preparado.
- Filtros por categoría.
- Datos guardados en el navegador mediante localStorage.
- Funciona como web estática, ideal para Netlify/Vercel/GitHub Pages.

## Uso
Abre `index.html` o sube toda la carpeta a Netlify.

## Nota sobre voz en iPhone
Safari puede limitar Web Speech Recognition dependiendo de la versión. Si el botón interno no funciona,
puedes tocar el campo de texto y usar el micrófono del teclado del iPhone.
